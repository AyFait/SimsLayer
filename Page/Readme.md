#SimsLayer is aimed to be fully cloudbased, here the page hosting the tool is lauched!
>+ Frontend => html + css + js (react/next, angular, vue, solid) - html + css + python - either
>+ Backend => node.js, express.js, nest.js, fastify - django, pyycore - [deal.ii (c++)](https://www.dealii.org).
>+ Model engine/framework => [GNN](https://cs.mcgill.ca/~wlh/comp766/files/chapter4_draft_mar29.pdf) ([pytorch](https://pytorch-geometric.readthedocs.io/en/latest/), [tensorflow](https://github.com/tensorflow/gnn))

## How to run

The page is a React app built with Vite. From this folder:

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 5173
```

Then open http://127.0.0.1:5173
